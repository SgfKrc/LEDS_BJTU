## 已完成票 `AUD-AUTH-01`

验收结果：
- `src/model_api_access.py` 统一提供模型 API 来源门：默认只允许 loopback；跨机访问必须显式设置 `QLH_MODEL_API_TRUSTED_CIDRS`，无效/未配置时 fail-closed。
- 单体 `api_server` 与 `inference-svc` 的模型加载/切换、注册、下载、GGUF、本地资产接口均接入来源门；网关继续负责 Web Bearer 会话和 owner/admin 管理员角色。
- `gateway` 的 registry/GGUF/download 路由现在向 control-svc 透传 Bearer；`control-svc` 默认绑定 `127.0.0.1`，避免绕过网关直接暴露控制面。
- 测试证据：`tests/test_model_api_access.py` 5 passed；gateway 全量 122 passed；gateway/control TypeScript build passed；模型下载和 inference-svc 相关 Python 回归通过。
- 远程部署配置约束已明确：必须由 gateway 提供登录入口，或显式配置受控 Tailnet/CIDR，并在防火墙层限制 control-svc；不能仅依赖默认监听地址。

## 后续票 `DEF-P1`
