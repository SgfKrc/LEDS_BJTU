# Android UI 统一风格改进计划

> 更新日期：2026-08-23  
> 状态：Android UI 分期本机开发完成，等待真机与低端设备验收  
> 适用范围：`android/` Compose 客户端，与 `frontend_cybergothic/` 的产品语义和视觉令牌对齐

## 1. 目标与边界

Android 不复制 PC 的桌面布局、密集侧栏、全屏 Canvas 或循环动效。两端统一的是产品语言：QLH 标识、黑白主题、低圆角、细边框、分层表面、清晰的状态色、紧凑的操作密度和一致的中英文术语；Android 保留触控优先、单列滚动、系统返回和小屏可读性。

性能边界：

- 禁止首页或页面背景使用持续运行的粒子、视差、视频和大型 Canvas 场景。
- 允许每个页面最多一组静态几何角标/线条，使用 Compose 的轻量绘制或普通布局，不参与动画和触摸事件。
- 动效默认关闭；必要的页面状态变化只使用系统级短时过渡，并服从无障碍减少动效偏好。
- 深色保持近黑底白字，浅色保持白底黑字；苍紫、暗金和荧光绿只承担品牌强调或状态语义，荧光绿不成为大面积主色。

## 2. 当前差距复核

| 差距 | 当前表现 | 处理策略 |
|---|---|---|
| 表面层级 | Android 主要依赖 Material 默认容器，PC 使用 veil、raised、sunken 和线框 | 建立 Android 对应 surface/line/accent 令牌 |
| 形状 | Android 已有 8dp 圆角，但设置卡缺少明确边界 | 保留触控友好的 8dp 上限，补细边框和静态角标，不使用大圆角 |
| 强调色 | Android 主题几乎全中性，PC 对当前项、品牌和状态有明确语义 | 苍紫用于选中/导航，暗金用于结构/等待/辅助操作，荧光绿用于当前/可执行状态 |
| 页面骨架 | 顶部栏和底部导航是标准 Material 形态 | 统一标题、分隔线、选中指示器和连接状态的层级 |
| 内容密度 | 设置、会话、图像页面的组件语言不完全一致 | 复用 `QlhTopBar`、`SettingsGroup`、`SettingRow` 和统一间距 |
| 背景图案 | Android 无品牌识别细节 | 仅增加静态短线/角标，不复制 PC Canvas |

## 4. AND-UI-01 实施范围

本票只触及共享主题和 Shell，不改变后端接口、业务状态、模型加载或导航路由：

1. 增加 Android 侧 surface、line、品牌强调和间距令牌，并保持黑白主题基线。
2. 顶部栏增加细边界和静态角标，标题/副标题与 PC 的层级一致。
3. 设置分组增加低对比线框，避免“Material 卡片堆叠”观感。
4. 底部导航选中态使用品牌强调容器，非选中态保持中性灰。
5. 不添加自动播放、循环计时器、复杂绘制或新的运行时依赖。

## 5. AND-UI-02 实施范围

1. Assistant 气泡和加载状态使用低对比暗金边界/指示，用户气泡仍使用黑白高对比正文。
2. 输入框聚焦和可发送按钮使用荧光绿，仅出现在交互焦点和执行动作，不铺满页面。
3. 当前会话使用暗金结构边界、荧光绿状态标签和苍紫容器，普通会话保持中性表面。
4. 复制、附件、删除等图标保持 48dp 触控目标和清晰的 content description。
5. 不改变消息持久化、会话路由、键盘避让和模型请求逻辑。

## 6. AND-UI-03 实施范围

1. Diffusion 使用统一顶部栏；提示词/步数输入聚焦边框使用荧光绿，参考图、任务状态和结果边界使用暗金或中性线框。
2. 生成按钮只在可执行时使用荧光绿；失败沿用错误语义，完成状态使用暗金完成容器。
3. 模型舰队、SAF 模型行和主节点 GGUF 下载行使用低圆角细边框，下载进度用暗金，校验完成用荧光绿。
4. 不改变 SD 请求、SAF 授权、下载进度、SHA 校验或模型选择状态；不新增背景动效和大图缓存。

## 7. AND-UI-04 实施范围

1. 集群、认证、审计、管理和诊断区域复用同一套状态语义：可达/可执行使用荧光绿，等待/未知使用暗金，失败/撤销使用错误色，其他状态使用中性苍紫容器。
2. 管理成员和审计列表默认只展开最近 8 条，保留“查看全部/收起”入口；该限制只改变移动端首屏密度，不删除任何撤销操作或后端数据。
3. owner/admin、认证能力和审批未迁移状态继续 fail-closed 展示，不新增权限、不伪造审批按钮、不把 token、session、secret 或路径写入 UI。
4. 本票只改 Android 展示层与共享组件，不改变集群、Auth、审计、Tailnet 绑定和管理 API 契约。

## 8. AND-UI-05 实施范围

1. 共享 `SettingRow` 使用 48dp 最小触控高度，点击行声明 Button 语义；顶部标题声明 heading，标题与状态胶囊允许大字体下换行并以省略号收口。
2. Chat 新消息滚动改为无动画定位，避免长回复和状态更新反复触发动画；不新增粒子、视差、Canvas 场景或持续运行的自定义动画。
3. 会话列表继续使用 `LazyColumn`，会话卡标题和图像参数行允许字体放大时重新排版；Full/Lite 共用同一套低成本布局。
4. 增加 1.6 倍字体回归测试，覆盖会话卡、创建会话入口和基本触控可达性；真实 TalkBack、窄屏、截图和低端硬件验收后置。

## 9. 验收与后续

- 静态检查：主题令牌测试、Full/Lite Kotlin 编译和 `git diff --check`。
- 设备验收后置：至少检查深色/浅色、窄屏、字体放大、系统导航栏和低端设备滚动。
- 如果实机显示强调色过重，优先降低强调色面积和对比度，不回退到绿色主色。
- AND-UI-01/02/03/04/05 已完成本机实现，Android UI 分期转入真机、TalkBack、字体放大和低端设备验收；不把 PC Canvas、桌面侧栏或复杂动效移植到 Android。
