# QLH 答辩现场检查清单

> 票号：`DEF-A3`  
> 适用模式：无真实模型的 `fixture-defense`  
> 原则：先检查再启动；只处理本票拥有的进程；任何现场失败都准确降级，不用旧证据冒充当前运行

## 一键机器预检

在仓库根目录先执行受限重置，再运行预检：

```powershell
scripts\demo\reset.bat --apply
scripts\demo\checklist.bat
```

重置只处理经所有权票据和当前进程身份双重确认的本票进程；详见[环境重置说明](答辩演示-环境重置说明-2026-09-10.md)。若输出 `REVIEW_REQUIRED`，停止自动处理并人工确认，不得扩大到按名称或端口盲杀。

无提示时输出 `READY_FOR_MANUAL_CHECKS`；可选端口占用或电源不可观测时输出 `WARNING`，但仍会生成报告供人工复核。报告位于 `build/defense-preflight/latest.json`。它只检查本机运行时、浏览器、存储、电源可观测状态、loopback、端口和证据入口，不访问外网、不加载或枚举模型权重。

如需把电源未知、可选端口占用等警告也视为失败，使用：

```powershell
scripts\demo\checklist.bat --strict-warnings
```

## T-30 分钟：设备与电量

- [ ] `device-python`：Python 运行时检查通过。
- [ ] `device-node`：Node、npm 和现行 `frontend_cybergothic` 的 Vite 依赖检查通过。
- [ ] `device-browser`：Microsoft Edge 可用；不要临时下载浏览器。
- [ ] `device-storage`：仓库所在磁盘至少保留 1 GB，足够写脱敏 JSON、SVG、截图和 trace。
- [ ] `power-supply`：查看自动探测结果；未知状态必须人工复核。
- [ ] `manual-power-adapter`：接通电源，关闭系统省电/休眠，确认适配器和插座不会松脱。
- [ ] `manual-display`：接好投屏，确认 100%/125% 缩放下首屏声明可见；打开一个演讲者可见、观众不可遮挡的计时器。

阻断条件：Python/Node/Vite/Edge 缺失、磁盘不足，或者无法保障持续供电时，不进入现场动态演示。

## T-20 分钟：网络与端口

- [ ] `network-loopback`：本机 `127.0.0.1` 建连测试通过；fixture 不需要 DNS 或互联网。
- [ ] `manual-network-boundary`：保持当前网络/VPN/代理状态不再变化；不要为了 fixture 临时接入陌生网络。
- [ ] `port-frontend`：默认 `5174` 可绑定，这是 fixture 演示的唯一必需固定端口。
- [ ] `port-api`：`8000` 仅为 live/API 预留，本场占用只告警，不阻断 fixture。
- [ ] `port-cluster`：`8001` 仅为 live/cluster 预留，本场占用只告警；P2/P3 使用动态 loopback 端口。
- [ ] `manual-port-owner`：端口冲突时先查 PID/命令归属。不得按端口号盲杀进程，不得结束 IDE、数据库、用户已有服务或来源不明的进程。

端口冲突处理：若 `5174` 被非本票程序占用，选定空闲端口后执行 `demo.bat --frontend-port <PORT> ...`，始终以启动器实际打印的 URL 为准。

## T-15 分钟：模型与口径

- [ ] `model-scope`：自动结果必须为 `DEFERRED / non-blocking`；这表示模型不属于本场依赖，不表示真实模型已经验收。
- [ ] `manual-model-boundary`：打开[性能结题表](答辩演示-性能结题表-2026-09-10.md)，确认 TTFT、inter-token、E2E、tokens/s、显存与加载时间仍为 `NOT RUN`。
- [ ] 牢记不可说：真实模型推理已经通过、物理双机已经测试、fixture 毫秒数是 TTFT、`tasks/s` 是 tokens/s。
- [ ] 牢记可说：P2 使用真实第二进程与生产 task-worker 协议；P3 测量单机 TaskGraph 控制面 fixture；真实模型两张功能票已独立关闭，但性能与物理双机仍为 `NOT RUN`。

如果未来补入真实模型 JSON，也必须先通过 `qlh.real_model_performance.v1` 契约并重新生成性能结题表；不得现场手改 Markdown 数字。

## T-10 分钟：证据与彩排

- [ ] `evidence-contracts`：故事线、场景、拓扑、性能输入、环境重置和相关测试均存在。
- [ ] `recovery-entrypoints`：demo、benchmark、performance report、story、checklist 和 reset 入口均存在。
- [ ] `manual-evidence-tabs`：按顺序预开四页：拓扑页、故障 JSON、性能结题表、开发票计划。
- [ ] 执行 `scripts\demo\story.bat`，确认恰好 `300s / 6 segments`。
- [ ] 执行故障彩排并确认 `exit 23 → expired → retry 1 → completed`。
- [ ] 执行 benchmark，再执行 performance report；只读新生成的数值。
- [ ] 最后启动 topology 场景并保持窗口，不再修改依赖或配置。

推荐顺序：

```powershell
scripts\demo\reset.bat --apply
scripts\demo\story.bat
scripts\demo\demo.bat --mode failure --report build\defense-demo\failure-story.json
scripts\demo\benchmark.bat --report build\defense-benchmark\story.json --chart build\defense-benchmark\story.svg
scripts\demo\performance_report.bat --benchmark build\defense-benchmark\story.json
scripts\demo\demo.bat --mode fixtures --scenario topology --open
```

## T-2 分钟：最后人工门

- [ ] 页面顶部显示 `FIXTURE / REDACTED / NOT LIVE`。
- [ ] 性能结题表表 2/3 显示 `NOT RUN`，表 1 的单位是 `tasks/s`。
- [ ] 故障 JSON 不含请求、输出正文、凭据、绝对路径或动态端口。
- [ ] `manual-recovery-clock`：能不看文档说出“20 秒止损，转固定证据；少于 90 秒切紧急版”。
- [ ] 计时器归零；关闭通知、自动更新、睡眠和会抢焦点的程序。

以上任一声明门不满足时，不开始演示。

## 现场恢复动作

| ID | 触发条件 | 立即动作 | 明确口径 |
| --- | --- | --- | --- |
| `recover-browser` | 浏览器未自动打开 | 复制启动器打印的 loopback URL 到 Edge | 不把“进程启动”说成“页面已验证” |
| `recover-port` | `5174` 被占用 | 查清归属；非本票进程不杀，改空闲端口 | 以新 URL 为准 |
| `recover-fixture` | 页面 20 秒未就绪 | `Ctrl+C` 停止本次入口，展示源码/测试/固定 JSON | 说“本轮 UI 未成功复演” |
| `recover-failure` | 故障链未完成 | 停止重跑，转确定性测试或已有报告 | 已有报告只能称“历史彩排” |
| `recover-benchmark` | benchmark/SVG 失败 | 转性能结题表声明矩阵；没有当前 JSON 就不读数 | 不引用旧机器或记忆中的数值 |
| `recover-power` | 低电量/掉电 | 先接电；不能稳定供电则停止动态重跑 | 固定证据仍可讲，当前运行不可声称 |
| `recover-time` | 剩余不足 90 秒 | 进入[90 秒紧急故事线](答辩演示-5分钟故事线-2026-09-10.md#90-秒紧急版) | 不再启动新命令 |

恢复纪律：

1. 一次动态步骤最多重试一次，20 秒仍未恢复就止损。
2. `Ctrl+C` 只发给当前启动器窗口；不要使用按名字批量杀 Python/Node 的命令。
3. 不删除仓库、模型目录、日志或用户状态来“修复”现场问题。
4. 临时换端口后，报告和浏览器必须指向同一个新端口。
5. 当前运行、历史彩排、自动测试三类证据必须口头区分。

## 演示结束

- [ ] 在启动器窗口按 `Ctrl+C`，等待其回收自己创建的子进程。
- [ ] 确认浏览器不再刷新、演示端口不再监听。
- [ ] 保留本轮脱敏报告；不复制包含系统隐私的终端全屏截图。
- [ ] 若发现残留，先运行 `reset.bat` 预演；仅在报告无错配时使用 `reset.bat --apply`，不现场盲删或盲杀。
