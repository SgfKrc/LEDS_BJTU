  ②后端已定义而前端未消费（功能缺 UI/未接线）。

## 2. 工具规格（`scripts/api_gap_scan.py`）

### 2.1 后端导出（静态 AST，不依赖服务在线）
- FastAPI 面：扫 `src/**/*.py` 中 `@app.<method>("<path>")` / `@router.<method>("<path>")`
  装饰器（`app`/`router` 为 FastAPI/APIRouter 实例），method ∈ get/post/put/delete/patch/head/options；
- 网关面：扫 `gateway/src/**/*.controller.ts`，`@Controller("<prefix>")` + 方法装饰器，
  路径 = `/api` + prefix + 方法 path；
- 产出条目：`{method, path_raw, source, file, line}`。

### 2.2 前端导出（静态扫描 JS/TS）
- 扫 `frontend/src/**/*.{js,ts,jsx,tsx}` 与 `frontend_cybergothic/src/**/*`：
  - `request(...)` / `fetch(...)` 第一参数为字符串或模板字面量，且形如 `/...`（或 `\`${BASE}…\`` / `BASE + path`）；
  - method 从同调用 `method: 'X'` 推断，缺省 GET；
  - 模板字面量中 `${...}` 归一化为 `{param}`；
- 产出条目：`{method, path_raw, source, file, line, kind: literal|template}`。

### 2.3 归一化与比对
- `normalize(path)`：补/剥 `/api` 前缀一致性，去 query，`{x}`/`:x`/`${...}` → `{param}`，去尾斜杠；
- 集合：F（前端引用）、B（后端定义，按 FastAPI 面/网关面分别）：
  - **缺口 A** = F − B：前端调了但后端没定义 → 404/未实现风险（最高优先）；
  - **缺口 B** = B − F：后端已定义但前端未消费 → 功能缺口（用户点名关注）；
  - **对齐** = F ∩ B；method 不同（如前端 GET 后端仅 POST）单独列「软缺口」。

### 2.4 报告与退出码
- 人类可读分节 + `--json` 全量导出（供 CI/证据）；
- `--ownership` 输出按归一化 endpoint 聚合的 ownership 表；`--json` 增加稳定 `ownership_schema=qlh.api_ownership.v1`、`summary.ownership_counts` 和 `ownership` 数组；
- 参数：`--include-gateway`（gateway/src controllers）、`--include-control`（control/src
  controllers）、`--only <子串>` 过滤、`-o <file>` 落盘；
- 缺口 B 内置内部面标注（`is_internal`：非 `/api` 前缀或 bootstrap/android/
  register/heartbeat 等关键词，标 `[i]` 与 JSON `internal` 字段），降噪音但**不隐藏**；
- 退出码（`exit_code()`）：0=对齐；1=有缺口 A；2=有缺口 B；3=A+B。提取失败=10。

### 2.5 边界与误报控制
- 只扫**字面量/模板字面量**，动态拼路径（`BASE + fullPath` 变量）不计入（README/文档声明）；
- 前端 `method` 推断：显式 `method: '…'` 优先；`const path = '…'` 形态标 `?`（比对时匹配
  任意后端方法）；不确定不猜；
- **router prefix 已静态展开**（`APIRouter(prefix=…)`/`@Controller('…')` 拼入最终路径，
  如 inference_service 的 `/v1` 面），不产生伪缺口；
- 报告头部输出扫描基线（条目数与来源分布），保证机械可复现。
