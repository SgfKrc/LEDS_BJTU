## 2. 状态口径

| 状态 | 含义 |
|---|---|
| `Completed（开发）` | 代码、自动化和本地可复现开发门已完成；不隐含真实环境或发布验收。 |
| `Ready` | 前置设计、代码落点和自动化边界明确，可在当前开发机开始。 |
| `Conditional` | 技术上可写，但尚缺固定范围、指标或显式业务决策，不应直接开工。 |
| `Validating / Blocked` | 开发门已关闭或无法继续，下一步只能等待真实设备、网络、账户、资源或安装环境。 |
| `Frozen` | 有明确止损或双基线风险，恢复条件未满足前不推进。 |

以下分类按阶段门而非代码行数计算；真实验收缺口不会抵消已完成的本地开发，也不能被本地测试替代。
