# 前端、安卓与后端接口及功能缺口审查

> 审查日期：2026-08-22  
> 状态：审查基线完成；`FE-AUD-01/02`、`CY-API-01/02/03/04/05/06/07`、`AND-API-01/02/03/04/05`、`BUNDLE-M1`、`EX-N3-PROD`、`DOCAGENT-M2-GATE/M3-QA` 已实现本机开发门；DOCAGENT 分支已收口
> 适用范围：`frontend_cybergothic`、Android Full/Lite、Python 单体后端、control/gateway 面；旧 `frontend/` 仅作历史对照

## 1. 结论摘要

QLH 当前没有确认的“新前端调用不存在后端接口”缺口。后端接口已经存在但新前端尚未形成完整用户工作流的能力，当前集中在：Auth App 首次配置与恢复码、集群档案激活/端点/层配置、任务图/Sidecar 诊断；Models、Local RAG 和 Image Studio 的第一轮控制面已收口。

Android 的 HTTP 控制面已覆盖登录、会话、聊天、远程 SD、主节点 GGUF 下载、bootstrap 和节点注册；本地 Room/Keystore、下载 Range/SHA、更新包校验、presence lease、Worker v2 协议和 Full Worker 的统一 Stage executor 已有开发门。尚未形成产品闭环的是 Auth App 配置和日志/更新 UI 的接线。真实设备/长时/温控/认证验收后置。

旧 `frontend/` 从本次审查起冻结：不再新增功能、接口或视觉票，只保留作行为和接口迁移对照。新前端唯一开发目标为 `frontend_cybergothic/`。

## 2. 审查方法与扫描证据

### 2.1 机械扫描

使用既有工具：

```powershell
.venv-test\Scripts\python.exe scripts\api_gap_scan.py --include-gateway --include-control --json
.venv-test\Scripts\python.exe scripts\api_gap_scan.py --include-gateway --include-control --ownership
```

审查前的混合基线为后端 `417` 条、前端 `255` 条；缺口 A `0`、缺口 B `138`、方法软缺口 `2`。`FE-AUD-01` 完成后，默认 canonical 扫描只包含 `frontend_cybergothic`：证据条目 `214` 条，缺口 A `0`、缺口 B `182`（内部协议 `115`、未消费 `67`）、软缺口 `0`；显式加入旧前端后为 `canonical=214 + legacy=161`，缺口 B `116`（内部协议 `107`、未消费 `9`）、软缺口 `0`。`FE-AUD-02` 在相同 JSON 中增加 `ownership_schema=qlh.api_ownership.v1`、`ownership_counts` 和按 endpoint 聚合的 `ownership` 数组；三面真实 ownership 域分类为 experimental `5`、internal protocol `120`、product `167`。证据条目包含共享 client 路由和页面/组件/Hook 的受限 symbol-call，不等同于唯一接口数量。

### 2.2 误报边界

- 默认工具只扫描 `frontend_cybergothic`；旧 `frontend/` 只有传入 `--include-legacy-frontend` 才进入对照。不能把混合数量视为新前端能力。
- TypeScript 泛型调用窗口已修复；跨行 `request<Result<...>>()` 不再截断 method，当前软缺口为 `0`。
- 缺口 B 包含节点内部、bootstrap、Android register/heartbeat、Qwen3 data plane 和 gateway/control 重复路由；这些不应复制成普通用户按钮。
- 报告会区分 `shared_client` 声明与页面/组件/Hook 的静态 symbol-call 证据；无法追踪的动态调用仍只算共享 client 证据，不宣称完整运行时覆盖。
- ownership 的 `domain` 与 `frontend_status` 分离：`experimental`/`internal_protocol` 描述后端契约域，`page_consumed`/`component_consumed`/`hook_consumed`/`client_declared`/`unconsumed` 描述前端证据；不得把实验或内部接口因有页面/Hook 证据而降级为普通产品接口。
