这里是**历史文档**：已被新方案取代、或已完成使命的计划与调研原始材料。保留它们的目的是
让后来的结论**可回溯**（为什么当初这么决定、当时的证据是什么），而不是当作现行口径 ——

## 两个约定

1. **归档区不在链接质量门内**：`scripts/check_doc_links.py` 显式跳过 `archive/`。归档文档
   保留着写作当时的引用写法（例如直接写文件名、或指向当时同在 `docs/` 的现行文档），
   这些历史引用**不要求**跟着现行结构和文件名变动 —— 事实来源是它们写的内容，不是它们的链接。
   本次整理只修了「因为加了分类子目录而**新**失效」的引用，既有失效保持原样。
2. **新增归档请放进对应子目录**：把文件移进来后，记得同步更新现行文档里指向它的链接；
   `python scripts/run_doc_checks.py` 会在 push 前 / CI 里告诉你有没有漏改。
