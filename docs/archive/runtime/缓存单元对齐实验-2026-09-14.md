# CACHE-04 缓存单元对齐实验（2026-09-14）

> 状态：**现行**
>
> 更新日期：2026-09-15

## 目的

验证固定 token 间隔下，分页边界和可复用缓存单元是否能形成稳定、可重算的前缀命中口径。实验只使用确定性的 token id，不加载模型、不访问 provider，也不把结果当作真实命中率。

## 固定布局

| 参数 | 值 |
| --- | ---: |
| `page_size` | 8 |
| `unit_size` | 4 |
| 每页缓存单元数 | 2 |
| 12 token 的单元边界 | `0, 4, 8, 12` |
| 12 token 的完整页边界 | `0, 8` |

`unit_size` 必须整除 `page_size`；`PagedKVCache` 默认将一个物理页作为一个缓存单元，也可显式传入更小且可整除页大小的单元间隔。未完成一个完整单元的尾部不会进入可复用前缀。

## 跨请求结果

缓存基准前缀为 8 token，按完整单元摘要匹配：

| 场景 | 原始公共前缀 | 完整单元命中 | 命中单元数 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 在完整单元后追加内容 | 8 | 8 | 2 | 可复用前两个单元 |
| 下一个完整单元发生变化 | 4 | 4 | 1 | 只复用首个完整单元 |
| 单元内部发生变化 | 2 | 0 | 0 | 不把半个单元算作命中 |
